校外研修 参加報告｜先生方へのおすそわけ

生成AI、まずは「下書き係」として使ってみませんか

研修：教職員向け 生成AI活用研修 日時：2026年10月27日 会場：川崎市立橘高等学校

3行で研修でわかったこと

  1. AIは「ゼロから考える時間」を減らす下書き係。仕上げと判断は先生がする。
  2. うまく使うコツは、AIへの頼み方。「誰として・何のために・どんな条件で・どんな形で」を書くだけで答えが変わる。
  3. 研修では、そのまま写して使える「お願い文」が約40種類配られた。授業・担任・事務・部活と進路まで、ほぼ全部の場面にある。

約束使う前に守る3つ

川崎市の「利用前研修」の資料で、一番大きく書かれていたことです。あわせて、入力した内容をAIに覚えさせない設定で使うことも求められています。

入れるとき個人情報は入れない

生徒の名前・成績・住所、外に出せない情報は書かない。名前は「生徒A」などに置きかえる。

できあがったとき中身は必ず確かめる

AIはまちがいをもっともらしく書くことがある。事実・数字・人名は自分で確認する。

使うとき他人の作品をまねない

できた文章や絵が、誰かの作品とそっくりになっていないか見てから使う。

手続き使い始めるまで

市立学校では、次の手順をふむと校務で使えるようになります。

  1. 利用前研修を受ける市の研修スライドを見る
  2. チェックリストを出す校長へ提出する
  3. 校長が確認・承認使ってよいと伝えられる
  4. 使い始める研修の約束を守って使う

使えるのは、学校のアカウントで入る Copilot Chat（マイクロソフト）と Gemini・NotebookLM（グーグル）。どれも「チャットで頼むと文章を返してくれる」道具です。チェックリストは研修資料（Plant「3チェックリスト」）か、SAINS-WEBの研修ページから入手できます。

コツ頼み方で答えが変わる

配られたお願い文は、どれも同じ4つの部品でできていました。

① 役わりを決める「あなたは高校2年の担任です」
② 何をしてほしいか「保護者会のあいさつ文を作って」
③ 条件をつける「3分くらい」「自己紹介・クラスの様子・今後の3部」
④ 答えの形を決める「表で」「3案出して」「理由も書いて」
ふつうの頼み方

保護者会のあいさつを書いて。

→ どこの学校でも使える、ぼんやりした文になる。

4つの部品を入れた頼み方

あなたは高校1年の担任です。保護者会のあいさつを、3分程度で、自己紹介・クラスの様子・今後の方針の順に書いてください。「一緒に育てていきたい」という気持ちを伝えたいです。

→ そのまま手直しに入れる下書きになる。

お願い文に出てくる「#」は見出しの印です。気にせずそのまま貼ってかまいません。「〇〇〇」のところだけ自分の内容に書きかえます。

実例研修で特にあつかった3つ

時間がかかる仕事ほど効果が大きい、という話でした。下の箱の文をコピーして、〇〇〇を書きかえて使えます。

授業｜小テスト・練習問題づくり

まちがえやすい所をつく4択問題を作る

# 依頼
あなたは日本の高校で〇年生の〇〇〇の授業を担当する教員です。
生徒向けの練習問題として、〇〇〇に関する選択問題を作成してください。

# ルール
・間違いの選択肢は「生徒が陥りやすい勘違い」に基づいて作成すること。
・各問題に、正解だけでなく「なぜその誤答を選んでしまうのか」という解説をつけること。

# 出力形式
・問題文
・AからDまでの4択の選択肢
・解答
・解説
・誤答の分析

授業で使ったプリントやスライドを添付して「この資料をもとに」と書くと、授業に合った問題になる。添付する前に名前などは消す。

担任｜通知表・指導要録の所見

所見の文例を3案もらう

# 依頼
あなたは高等学校〇年生のベテラン担任です。
次のルールを必ず守り、生徒の特徴をもとに、高校の通知表の所見を表形式で出力してください。

# 生徒の特徴
・〇〇〇（性格）
・〇〇〇（係・委員会・部活など）
・〇〇〇（がんばっていること）

# ルール
・案は3個挙げてください。
・250〜300文字で書いてください。
・参照の文を例にしてください。

# 形式
・表形式
・列は「案1」「案2」「案3」

# 参照
（自分が以前に書いた所見を1つ、名前を消して貼る）

生徒の名前は入れない。特徴だけを書く。「参照」に自分の文を入れると、自分らしい書きぶりに近づく。

進路｜志望理由書を見るとき

志望理由書の添削と、生徒へのアドバイスを分けて出す

# 依頼
あなたは高校生の志望理由書を専門に添削・指導するプロの指導者です。
高校生が【〇〇大学〇〇学部】に提出するために書いた志望理由書を、添削ポイントと添削方針に基づいて丁寧に添削してください。

# 志望理由（原文）
〇〇〇

# 添削ポイント
1. 進学・就職の目的がはっきりしているか
2. 相手（学校・学部・企業）のことを調べた跡があるか
3. 本人の具体的な経験が入っているか
4. 導入→理由→経験→将来 の順で自然に読めるか
5. 将来の姿と志望先がつながっているか

# 添削方針
・高校生らしい表現は残し、幼すぎる表現は直す
・内容が薄いときは、何を足せばよいかを指導として示す
・書きかえすぎず、「なぜ直すのか」をはっきりさせる

# 出力形式
【① 添削後の文章】
【② 生徒への指導ポイント】
【③ 主な修正箇所とその理由】

①をそのまま渡すのではなく、②を面談で使うと、生徒が自分で書き直せる。

一歩明日からの1週間で試すなら

いきなり授業で使わなくて大丈夫です。失敗しても困らないものから。

まず

チェックリストを出して、使える状態にする。

1日目 5分

メールの文面を頼んでみる。「以下の内容でメールの本文と件名を考えて。丁寧な敬語で、簡潔に」＋伝えたいことを箇条書き。

2〜3日目

小テストの問題を作らせてみる。上の「4択問題」のお願い文をコピーして、単元名だけ書きかえる。

週の後半

気に入らない答えが来たら、「もっと短く」「高1向けに」「別の案を3つ」と言い返してみる。何度でも直してくれるのが人との一番のちがい。

一覧配られたお願い文（約40種類）

★は研修で特にあつかったもの。全文は研修資料「プロンプト一覧」にあります。

授業

  • 単元の指導計画／1時間の授業案
  • 授業の始めに興味を引く話（3案）
  • 生徒から出そうな質問の洗い出し
  • スライドの構成案
  • ★問題づくり／資料からの問題づくり／似た問題づくり
  • 評価の観点表（A・B・C）づくり
  • 文章の手直し・翻訳、小論文・英作文の添削
  • 記述問題の採点、テスト結果の分析
  • 話し合い活動の設計、探究の問いを一緒に考える相談相手（生徒用）

担任

  • 文化祭の企画タイトル案（LHR用）
  • 学年目標・スローガン案
  • 席がえの座席表
  • あいさつ原稿、保護者向けプリント、学年・学級通信
  • 校外学習の行程表
  • メールの文面・返信
  • 面談で使う質問リスト、ふり返りシート
  • ★通知表・指導要録の所見の文例
  • アンケート結果の分析

事務

  • Excelの計算式づくり
  • 保護者からの意見への返信文
  • 購入・導入のための稟議書
  • 自己評価シートの方策づくり

部活動・進路

  • 練習メニュー、試合前の気持ちの整え方
  • ★志望理由書の添削
  • 模擬面接の質問と流れ
  • 大学への推薦書のたたき台
  • 進路を考える・オープンキャンパスの準備（生徒用）
