3行で研修でわかったこと

  1. AIは「ゼロから考える時間」を減らす下書き係。仕上げと判断は先生がする。「使うか使わないか」ではなく、「どう使うか」を考える時期に来ている。
  2. うまく使うコツは、AIへの頼み方。「誰として・何のために・どんな条件で・どんな形で」を書くだけで答えが変わる。
  3. 研修では、そのまま写して使える「お願い文」が約40種類配られた。授業・担任・事務・部活と進路まで、ほぼ全部の場面にある。

しくみAIはどこまで賢い？

研修の最初に紹介された数字です。2026年の共通テスト（東大受験科目・1000点満点）を、いまのAIに解かせた結果です。

文系937〜970 点
理系909〜968 点

3社のAI（ChatGPT・Gemini・Claude）の結果。出典：株式会社LifePrompt の検証（2026年1月、研修資料より）。

それでも、AIの答えをそのまま信じてはいけない理由も説明されました。

  • AIは意味を考えて答えているのではなく、「次に来そうな言葉」をつないでいる。だから、まちがいをもっともらしく言うことがある。研修では「水は何度で沸騰しますか」に「−15度で沸騰します」と答えた画面が紹介された。
  • 答えにかたよりが出ることがある。「政治家の絵」を頼むと男性ばかり、「看護師の絵」を頼むと女性ばかりになる例が示された。

約束使う前に守る3つ

川崎市の「利用前研修」と講師の資料の両方で、くり返し出てきたことです。あわせて、入力した内容をAIに覚えさせない設定で使うことも求められています。

入れるとき個人情報は入れない

生徒の名前・成績・住所、外に出せない情報は書かない。名前は「生徒A」などに置きかえる。

できあがったとき中身は必ず確かめる

AIはまちがいをもっともらしく書くことがある。事実・数字・人名は自分で確認する。

使うとき他人の作品をまねない

できた文章や絵が、誰かの作品とそっくりになっていないか見てから使う。

実際に、東京都の高校で、文化祭のパンフレットの絵をAIで作って配ったところ、あるイラストレーターの絵とそっくりで問題になった例が紹介されました。

教科書をAIに読み込ませて問題を作ってもいい？

授業で使うためならOK

授業の問題やワークシートを作るために、教科書や資料を読み込ませるのは、原則として認められている（著作権法35条）。

問題集の代わりはNG

市販のドリルや問題集を買わなくて済むほど大量に作って配る、といった使い方は、出版社の利益をうばうのでだめ。

生徒の家庭学習も同じ考え方です。自分の勉強に使うのはOK、作ったものを外に出す（SNSにのせる・配る）のはNG、やりすぎ（丸ごと読み込ませる）は注意。

川崎市のいまのルール：AIで作った画像は校外に出さない

研修の最後に、主催側から連絡がありました。AIで作った画像は、授業の中で使うのはよいが、学年通信・学級通信などで校外に出すことは、いまの情報・視聴覚センターのルールではできない、とのことです。11月ごろに緩和の通知が出る予定で、使えるようになったら管理職から連絡があるそうです。ルールは研修のClassroomにも載っています。

手続き使い始めるまで

市立学校では、次の手順をふむと校務で使えるようになります。

  1. 利用前研修を受ける市の研修スライドを見る
  2. チェックリストを出す校長へ提出する
  3. 校長が確認・承認使ってよいと伝えられる
  4. 使い始める研修の約束を守って使う

使えるのは、学校のアカウントで入る Copilot Chat（マイクロソフト）と Gemini・NotebookLM（グーグル）。どれも「チャットで頼むと文章を返してくれる」道具です。チェックリストは研修資料（Plant「3チェックリスト」）か、SAINS-WEBの研修ページから入手できます。

仕事で使う前に、画面の表示を確かめる。学校のアカウントで入ると、「入力した内容はAIの学習に使われない」ことを示す盾のマークなどの表示が出ます。講師は「家で料理の相談をするのとはちがう。仕事では、この表示があるアカウントで使ってほしい」と話していました。

コツ頼み方で答えが変わる

講師が示した「伝わりやすい頼み方」は、5つの部品でできていました。

① 役わりを決める「あなたは普通科高校の親切な講師です」
② 相手を書く「14歳の生徒に向けて」
③ 状況を書く「生物の試験の準備として」
④ してほしいことを書く「光合成のしくみを説明して」
⑤ 字数や口調を決める「300字で、授業らしい口調で」
コツは3つはっきり・具体的に・何度も試す
ふつうの頼み方

保護者会のあいさつを書いて。

→ どこの学校でも使える、ぼんやりした文になる。

部品を入れた頼み方

あなたは高校1年の担任です。保護者会のあいさつを、3分程度で、自己紹介・クラスの様子・今後の方針の順に書いてください。「一緒に育てていきたい」という気持ちを伝えたいです。

→ そのまま手直しに入れる下書きになる。

入力欄で改行するときは Shift＋Enter。Enterだけだと、途中で送ってしまいます。多少の誤字や、整っていない文でもAIは読み取ってくれます。

お願い文に出てくる「#」は見出しの印です。気にせずそのまま貼ってかまいません。「〇〇〇」のところだけ自分の内容に書きかえます。

実例研修で特にあつかった3つ

時間がかかる仕事ほど効果が大きい、という話でした。下の箱の文をコピーして、〇〇〇を書きかえて使えます。

授業｜小テスト・練習問題づくり

まちがえやすい所をつく4択問題を作る

# 依頼
あなたは日本の高校で〇年生の〇〇〇の授業を担当する教員です。
生徒向けの練習問題として、〇〇〇に関する選択問題を作成してください。

# ルール
・間違いの選択肢は「生徒が陥りやすい勘違い」に基づいて作成すること。
・各問題に、正解だけでなく「なぜその誤答を選んでしまうのか」という解説をつけること。

# 出力形式
・問題文
・AからDまでの4択の選択肢
・解答
・解説
・誤答の分析

授業で使ったプリントやスライドを添付して「この資料をもとに」と書くと、授業に合った問題になる。添付する前に名前などは消す。物足りなければ「国公立大レベルに」「共通テストを意識して」と言い返すと、作り直してくれる。

担任｜通知表・指導要録の所見

所見の文例を3案もらう

# 依頼
あなたは高等学校〇年生のベテラン担任です。
次のルールを必ず守り、生徒の特徴をもとに、高校の通知表の所見を表形式で出力してください。

# 生徒の特徴
・〇〇〇（性格）
・〇〇〇（係・委員会・部活など）
・〇〇〇（がんばっていること）

# ルール
・案は3個挙げてください。
・250〜300文字で書いてください。
・参照の文を例にしてください。

# 形式
・表形式
・列は「案1」「案2」「案3」

# 参照
（自分が以前に書いた所見を1つ、名前を消して貼る）

生徒の名前は入れない。特徴だけを書く。「参照」に自分が前に書いた所見を入れると、自分らしい書きぶりに近づく。クラス全員分は、特徴を表にまとめて（名前は入れない）添付すると一度に頼める。ただし40人分を一度に頼むと抜けが出やすいので、「1〜10番まで」のように分けて頼む。

進路｜志望理由書を見るとき

志望理由書の添削と、生徒へのアドバイスを分けて出す

# 依頼
あなたは高校生の志望理由書を専門に添削・指導するプロの指導者です。
高校生が【〇〇大学〇〇学部】に提出するために書いた志望理由書を、添削ポイントと添削方針に基づいて丁寧に添削してください。

# 志望理由（原文）
〇〇〇

# 添削ポイント
1. 進学・就職の目的がはっきりしているか
2. 相手（学校・学部・企業）のことを調べた跡があるか
3. 本人の具体的な経験が入っているか
4. 導入→理由→経験→将来 の順で自然に読めるか
5. 将来の姿と志望先がつながっているか

# 添削方針
・高校生らしい表現は残し、幼すぎる表現は直す
・内容が薄いときは、何を足せばよいかを指導として示す
・書きかえすぎず、「なぜ直すのか」をはっきりさせる

# 出力形式
【① 添削後の文章】
【② 生徒への指導ポイント】
【③ 主な修正箇所とその理由】

①をそのまま渡すのではなく、②を面談で使うと、生徒が自分で書き直せる。「添削ポイント」は例なので、学校や大学に合わせて足したり変えたりしてよい、と講師も話していた。

一歩明日からの1週間で試すなら

いきなり授業で使わなくて大丈夫です。失敗しても困らないものから。

まず

チェックリストを出して、使える状態にする。

1日目 5分

メールの文面を頼んでみる。「以下の内容でメールの本文と件名を考えて。丁寧な敬語で、簡潔に」＋伝えたいことを箇条書き。

2〜3日目

小テストの問題を作らせてみる。上の「4択問題」のお願い文をコピーして、単元名だけ書きかえる。

週の後半

気に入らない答えが来たら、「もっと短く」「高1向けに」「別の案を3つ」と言い返してみる。何度でも直してくれるのが人との一番のちがい。最初から100点を期待しない。

いつでも

話題が変わったら「新しいチャット」を開く。前の話が残っていると、答えがずれる。急ぐときは速いモード、正確さがほしいときはじっくり考えるモードを選ぶ。

講師研修で心に残ったことば

研修の録音から、講師（認定NPO法人CLACK 宮脇裕貴さん）の話を要約しました。

AIに任せるところは任せて、人にしかできないところに時間を使ってほしい。

研修のはじめに

AIが広がって先生の役わりがうすくなるのではなく、むしろ価値は高まる。出てきたものを見きわめ、子どもに何を届けるかを考えるのは先生だから。

文部科学省のガイドラインの紹介で

一度で完ぺきなものはねらわない。部分ごとに頼んで、会話しながら直して、最後に合わせる。自分も毎日そうしている。

頼み方の練習のあとで

配ったお願い文は、きっかけにすぎない。「これをAIに任せたらよかった」「このお願い文が効いた」と、先生どうしで話して広げてほしい。

お願い文の一覧を紹介して

読みきれない長い資料（文化庁の著作権の手引きなど）こそ、AIに読ませて「先生に関係するところだけまとめて」と頼めばよい。

著作権の話の中で

こわがらせて終わりたくない。正しくおそれたうえで、便利に使ってほしい。

まとめで

質問講師への質問

報告者が最後に質問しました。「続けにくさ」をどうするか、という質問です。

問

お願い文をコピーして、〇〇〇のところを書きかえる。この手間で止まってしまう先生が多いと思います。よく使うお願い文をGemなどに入れて共有する、といった実例はありますか。

答

学校ごとに作りこむことはしていないが、教科ごとに使える「専用のAI」は作っている。たとえば探究と数学を組み合わせたものでは、生徒の興味（「犬が好き」など）から、どんなデータを集めて分析すればよいかを一緒に考えてくれる。こうした専用のAIやGemを作って共有し、最初の一歩のハードルを下げるのは有効だと、多くの学校と話していて感じている。ただし、よい面だけではないことも考えておく必要がある。

この答えを受けて、校内でもよく使うお願い文をGemにまとめて共有することを考えています（下の「4段階」の4にあたります）。

段階AIの使い方の4段階　自分はいまどこ？

講師は、AIの使い方を4つの段階に分けて示しました。段階に上下はなく、場面に合わせて選べばよい、という話でした。

  1. 1調べる・話す知りたいことを聞く。考えを整理する。
  2. 2　研修の中心頼む条件をつけて、下書きや案を作ってもらう。
  3. 3　次の目標いっしょに磨く「もっと短く」「別の案を」と言い返して、何度も直す。
  4. 4くり返しを仕組みにするよく使う頼み方をしまっておき、毎回同じ流れで使う。

4の例：Geminiの「Gem」という機能に、よく使うお願い文を登録しておくと、毎回コピーして貼らずに済みます。登録したものは同僚と共有することもできます。

AIを信用しすぎない、AIに任せきらない 講師のまとめのことば。事実の確認と最後の判断は、人がする。
